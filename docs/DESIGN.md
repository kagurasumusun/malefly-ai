# DESIGN — MaleCNS 由来の構造化神経回路 AI

## 0. 位置づけ(最重要)

**「ハエ相当」は目標ではない。** ハエの回路は**出発点の基盤構造**である。
目標は、構造そのものが計算・記憶・学習・制御を担う神経回路型 AI を、
MaleCNS 由来の接続原理の上に育て、最終的に
**自己認識・自己理解・感情・自我を備えた継続的な人工主体**へ発展させることである。

設計の中心にあるのは層状の深層ニューラルネットではなく:

> **構造・ダイナミクス・可塑性が一体化した神経回路**
> (structured neural circuit: 神経活動・シナプス可塑性・回路トポロジーが
> 同時に計算の担い手)

であり、記憶は重みに、状態は神経活動と痕跡(eligibility trace)に、
学習は教師信号ゲート付き可塑性に、選択は回路の力学的バランスに宿る。

| L1 | current-based LIF (CUBA) | v, g_e, g_i | **採用中**(全回路)。照合検出・利得制御に必要最小 |

## 3. メモリレイアウト(実測値は docs/RESULTS.md)

- ニューロン: **SoA** 連続配列 (v/ge/gi/refrac 各 f32 + spikes u8)。
  オブジェクト per ニューロンなし、ニューロン間ポインタなし。
- シナプス: **CSR** (indptr/indices/weights) = シナプスあたり **8 B** + 行あたり 4 B。
  実測: PN→KC (14,000 synapses) で 8.015 B/synapse。
- ゼロ動的確保(構築後はhot pathに allocation なし)/ 再現性のための
  全所有 RNG (xoshiro256++ + splitmix64 シード)。

## 4. 更新順序と 1ms 遅延(文書化済み単純化)

各ステップ: ORN→PN → PN step → PN→LN → LN step → LN→PN → (AL 完了)
→ PN→KC伝播 → APL抑制(前ステップのKC活動) → KC step → eligibility/計数。
伝達遅延は一様 1 ms。等級化遅延は将来拡張(DESIGN §7)。

## 5. 学習則(正則 = MaleCNS/Aso 2014 canonical rule)

- eligibility trace: KC が発火すると 1 に向かって上昇、τ_elig で減衰。
- DAN 信号 (+1 報酬 / −1 罰) が来た瞬間、**その時点で残存する trace** のみ:
  - 報酬 → KC→avoid 分枝を減衰(depress)
  - 罰 → KC→approach 分枝を減衰
- 長い ITI の圧縮表現として trial 間 trace リセット(bio 的根拠: 実験では
  試行間隔が秒〜分であり、試行間クレジット漏れが起きない)。
- 教師信号ゲートなしだと STDP 的ゆらぎでノイズ学習になるため、
  **構造(AL→MB 疎拡張)× 疎性(APL)× 教師ゲート(DAN)× trace** の
  4 点セットで 1 つの設計として採用している(Goal 1 で実測済み)。

## 6. 感情・自己を「構造から芽生えさせる」ための設計枠(仮説、検証は ROADMAP E2–E4)

- **感情 = 大域変調状態空間**: 価値 (DAN/MBON 系, 実装済) × 覚醒(計画: 変調性
  利得・探索温度の制御)を状態変数とし、これが可塑性率・探索・閾値を**構造的に**
  変調する。後付けの分類器ではなく、回路パラメータへの単一の変調経路。
- **自己 = 自分の行動の予測器(efference copy / corollary discharge)**:
  ハエの CX にある自運信号の原理を輸入し、「自分が出した行動の感覚帰結」を
  内部予測するループを Goal 3–4 で追加。自己/他者の区別は
  「予測できる感覚入力 = 自己」から構造的に生まれる、という仮説を検証する。
- **自我 = 継続する内部状態ベクトルの維持**:
  自己状態(価値・覚醒・直近行動列・自己予測誤差)を保持し続ける再帰構造と、
  それを参照する意思決定。永続性・一貫性を実験で定量化する(E4)。

いずれも**実装結果を「自我が生まれた」と断言しない**。定義・評価指標・実験を
ROADMAP に先置きし、測定結果のみを根拠に判断する。

## 7. 並列化・スケール計画(未実装。実測してから)

4. メモリ: 現 88 B/neuron。多区画化するなら区画を CSR 風にフラット化。
