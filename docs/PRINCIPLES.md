# PRINCIPLES — 本プロジェクトの絶対原則

1. **性能向上は必ず実測する。** 測定していない主張はしない。
2. **変更前後を必ず比較する。** 1 つの変更には 1 つの測定が付く。
3. **再現性を維持する。** 同じ seed は bit 単位で同一結果(run_hash で検証)。
4. **複雑さ・規模・忠実度は価値ではない。** 測定された能力だけが価値である。
   - より複雑 = より賢い、ではない
   - より多いニューロン = より賢い、ではない
   - 生物学的忠実度 = AI 性能、ではない
   - 巨大なモデル = 高性能、ではない
5. **CPU/GPU を増やすだけの高速化はしない。** アルゴリズム・データ構造の改良で測る。
6. **stub / fake / placeholder で機能や性能を偽装しない。**
   実装していない機能を実装済みと扱わない。
   ソフトウェア的な記憶(カウンタ等)を使う場合は「回路記憶」と明確に区別して
   両方を測定・報告する(Goal 2 の STM 設計を参照)。
7. **仮説と実証結果を明確に分ける。** 特に自我・感情・自己認識については、
   実装結果を以て「成立した」と断定しない。定義・指標・実験で検証する。
8. **既存実装を不用意に捨てない。** 実測に基づいて進化させる。
9. **データを失わない。** こまめに commit & push。結果(JSON/CSV)は成果物として
   リポジトリに残す。
10. **依存を増やさない。** C++17 標準 + ninja のみ。
