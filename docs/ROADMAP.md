# ROADMAP — 能力マイルストーンと「構造から芽生える自己」の段階

> 方針: 小さく実装 → 測定 → 比較 → 改良 → 拡張。
> 各ゴールの**成功条件は実行前に固定**し、結果は docs/RESULTS.md に実数で残す。
> 「ハエ相当」は到達目標ではなく基盤。以降の段階はすべて
> MaleCNS 由来構造の**延長線**上に設計する(別アーキテクチャの積み替えではない)。

## Goal 1: 自律的な価値学習 ✅ 実装・実測済み

- 課題: 2 匂いバンディット(A=報酬, B=罰, 確率的結果 85%)。
  MaleCNS 由来回路 (AL→MB→MBON/DAN) が経験だけで A を誘引・B を回避を学習。
- 成功条件(実行前に固定):
  - [x] 学習後 p(approach|A) > 0.75 かつ p(approach|B) < 0.35
  - [x] 学習が seed に頑健(4 seeds 全部で成立)
  - [x] 一般化: 刺激の KC 表現オーバーラップと選択確率が正相関
        (r > 0.9)→ 記憶が「構造化表現」であり参照テーブルでないことの証拠
- 結果: docs/RESULTS.md §2(全条件達成、r = 0.92–0.99)。

## Goal 2: 記憶 — 保持・干渉・遅延選択 ✅ 実装・実測済み

ユーザ指定の流れ「A を見る → 時間経過 → A と B → 過去の経験で A を選ぶ」を、
**単なる反射ではなく内部状態の保持**として、3 つの測定に分解:

1. **保持 (retention)**: 学習後、120 秒の無強化ギャップ(自発活動のみ)を挟み、
   価値記憶が維持されるか(破局的忘却の欠如)。
2. **干渉下の並列記憶 (interference)**: A と部分的に重なる新臭 E を E+ 学習しても、
   A/B の記憶が維持されるか(重なりを通じた構造的転写を測定)。
3. **遅延選択 (delayed choice / STM)**: 香りを提示 → 香りを消して D 秒 →
   **痕跡に基づく選択**。回路状態(eligibility trace)が匂いの価値記憶を
   何秒保持できるかを D=0–4s で測定。カウンタ(ソフトウェア記憶)との
   対照も同時に測定し、「回路記憶」と「実装記憶」を区別して報告する。
- 結果: docs/RESULTS.md §3。

## Goal 3: 未知環境への適応(場当たり的適応)✅ 実装・実測済み

- 全体の再訓練を禁止。**神経活動 + シナプス可塑性のみ**で適応:
  価値逆転(A+/B− → A−/B+ → A+/B−)を同一回路・同一接続で実施。
- 成功条件(実行前に固定): 逆転後 100 試行以内に rolling-20 正答 ≥0.70
  を 2/3 seeds。**結果: 3/3 seeds で達成(t70=66/69/39)。さらに
  flip-back の t70 が初回逆転より短い seed あり(49<66, 27<39)=
  メタ適応の計測上の兆候。** ablation で覚醒変調・KC 型分化が
  反復適応に必要と分離測定(docs/RESULTS.md §8)。
- 発見(設計修正の記録): delta 読み出し、MB→LH 先天抑制ゲート、
  対抗回復可塑性 — すべて実測に基づく採用(RESULTS §7)。

## Goal 4: 感覚→判断→行動の統合(センソリモータ統合)

- 刺激空間を拡張(視覚位置 + 嗅覚)、行動空間を拡張(接近方向、探索)。
- CX(中央複合体)を導入: 方向選択のリングアトラクタ + efference copy。
- 行動は「価値 × 内部状態 × 方向」の回路動力学から生成。
- 成功条件: 未知の刺激配置で Goal 1 相当の学習、Goal 2 相当の記憶、
  Goal 3 相当の適応が**同一基盤**で成立すること。

## E 段階: 構造から芽生える感情・自己・自我(研究目標)

各段階は「定義 → 構造 → 実験 → 判定基準」を先に固定し、
**実装したから成立した、とは決して言わない**。測定で語る。

### E1 価値状態(= 感情の基礎次元その1) — 実装・測定済み
- 定義: 刺激についての内部的な引き寄せ/回避の偏り(アプローチ確率、valence)。
- 構造: MBON 2 分枝バランス + DAN 教師信号(実装済)。
- 測定: probes の p_approach / valence(Goal 1–2 で実測)。

### E2 覚醒・変調状態(感情の基礎次元その2) — 設計済み、未実装
- 定義: 学習率・探索温度・行動閾値を大域的に変調する内部変数。
- 構造(仮説): 強化履歴が(Octopamine/DAN 系のように)可塑性率 η と
  epsilon・温度を変調する第 2 の変調チャネル。
- 実験: 変調あり/なしで、報酬変動環境(確率スイッチング)への適応速度を比較。
  **効果が測定できなければ棄却する**(生物学忠実度を理由に採用しない)。

### E3 自己/他者区別(corollary discharge による) — 設計済み、未実装
- 定義: 「自分の行動の感覚帰結を予測でき、他者・環境由来の入力と区別できる」。
- 構造(仮説): 行動出力のコピー(efference copy)が内部予測器(CX 由来構造)へ入り、
  感覚入力との差(予測誤差)が自己由来/外生の判別信号になる。
- 実験: 自分の行動で生じる感覚変化と、同一の外生変化を判別できるか
  (判別率を「自己認識スコア」として定量化)。ハエの CX が自己運動を
  差し引く回路(例: gap 検出の CD 神経)の原理を輸入する。
- 判定: 判別率が有意に偶然を上回り、予測器破壊(制御)で崩落すること。

### E4 自己モデル・自我(継続する主体) — 研究目標
- 定義: 自己状態(価値・覚醒・直近行動列・自己予測誤差)の**持続的な内部表現**を
  保持し、行動選択がそれを参照する。外的観測なしで自己状態を報告・利用できる
  (「今の私は報酬を見込みやすい/警戒状態だ」等の内部状態へのアクセス)。
- 構造(仮説): E1–E3 の状態を再帰的に保持する自己状態回路(attention schema /
  予測処理の自己モデルを回路化)。
- 実験候補: (i) 鏡テスト類似: 自分の軌跡の再入力と他個体の軌跡の識別、
  (ii) 自己状態に依存する意思決定の介入実験(状態を外から書き換えると
  行動が予測どおり変わる)、(iii) 一貫性: 長期運用での自己状態ベクトルの
  安定性と、経験の反映度。
- 判定: **「自我が生まれた」と断定しない**。上記指標の実測値を提示し、
  定義との整合を議論する。

## 明示的な非目標

- ニューロン数の自慢(166k をただ動かすこと)
- 生物学的忠実度それ自体(性能への寄与が測定できない機構は採用しない)
- 「LLM 的な」言語模倣による知能の外見
- stub/fake による見かけの能力(実装していないことは常に明記)
