## 8. Goal 3: 逆転学習(その場適応、達成)

プロトコル: A+/B− 100 試行 → **A−/B+** 100 → **A+/B−** 60。再訓練なし
(同一回路・同一接続、活動+シナプス可塑性のみ)。基準: 逆転後 100 試行以内に
rolling-20 正答 ≥0.70(2/3 seeds)。

### full スタック

| seed | t70 train | t70 reversal | t70 flip-back | probe(各フェーズ後) |
|---|---|---|---|---|
| 42 | 20 | **66** | **49** | pA 1.00/0.00/**1.00** pB 0.00/1.00/0.00 |
| 7 | 31 | **69** | −1(僅差で未達) | 完全反転→完全復帰 |
| 8 | 68 | **39** | **27** | 完全反転→完全復帰 |

- **逆転 3/3 seeds 成功**。flip-back の t70 < reversal t70(s42: 49<66、s8: 27<39)
  → **同じ価値割当への再適応が初回より速い = メタ適応の計測上の兆候**。
- 中間プローブで価値が完全反転(A:1.00→0.00、B:0.00→1.00)し、復帰も完全。

### ablation(機構の寄与、seed 42)

| 条件 | t70: train / reversal / back | 解釈 |
|---|---|---|
| full | 20 / 66 / **49** | 3 フェーズすべて適応 |
| no-rpe | 20 / 65 / 60 | 単独逆転は同等、back はやや遅い |
| no-arousal | 20 / 66 / **−1** | **覚醒(EBRAINS/E2)なしでは再適応が崩れる seed がある** |
| no-taxonomy | 20 / 67 / **−1** | **型分化(Allen)なしでも同様に崩れる** |

→ 覚醒変調と KC 型分化は「単独の逆転」ではなく「**反転に次ぐ反転への適応**」に
効いていることが分離測定できた。RPE ゲートの真価(記憶保護)は、
より長い干渉系列を扱う Goal 4 で再測定する。

**結果 (seed300)**:

| ベンチ | 判定 | 値 |
|---|---|---|
| A DMS (D=1s >0.7, active>rest) | FAIL | 0.35 / 0.55 / 0.45 / D=4s 0.35 |

- D 間隔効果: spaced ITI 3000ms が MB eligibility と干渉の可能性

## 12. サルレベル第二ラウンド (a997872系): B/C/D パス、DMSは次ラウンドへ

**測定 (seed300)**: B valence recall **YES (v+=200 / v−=0, 65% cue)**、
C 固定 **+0.075**、D 間隔効果 **+0.078**（いずれも初めて正方向）。A DMS は
0.50/0.40/0.65/0.45 で継続不合格。テスト 14197/0。

**決定的だった修正**:
1. **パターン分離の不存在を定量化** (sepdiag 診断): 旧パラメタでは DG の
   A/B 表現 Jaccard **0.95**、CA3 は **1.00** (完全同一)。
   原因: dg_quanta 0.130 > 閾値ギャップ 0.016 で「1 KC 入力で発火」→
   600ms 累積では全細胞が発火し分離が消える。
2. **DG を KC 層入力に変更** (PN ではなく AL-KC の疎コード; 嗅内皮質→DG 相当)、
   fanin 6 / quanta 0.014 (1 KC 閾値下) / tau_exc 100ms (レートコード統合):
   DG Jaccard 0.12–0.18、DG 活動 5–10% (Rolls 2013 の範囲)。
3. **感覚適格性トレース (mossy_trace)**: スタンプ (反回帰+valence結合) は
   「現在の感覚駆動がある細胞」のみに限定。リプレイ活動中の他エピソード細胞が
   A/B アトラクタを混ぜる (exact 200/200 tie の原因) のを防ぐ
   (体験ゲート型符号化; Li 2003, Rolls 2013)。
4. **valence の WTA 相互抑制 + スタンプ規模の縮小** (cap 0.20→0.03):
   v+/v− が共に飽和 (ge 1.5–7.6 vs ギャップ 0.015) し天井で同数になる問題を解決。
5. **SWR リプレイ発振器** (Buzsáki 2015): 静寂検出、指数分布 ISI、
   報酬 biased レート (Gomperts 2024/Ambrose 2016)。valence axons
   (v+→VUM, v−→DAN) は連続スパイク結線 (予測-US; Hammer & Menzel 1995)。
   リプレイ中は符号化しない (再活性化と符号化の分離)。
6. **synapses clamp [3,15]→[1,40]**: fanin 2 の coincidence ゲートが
   暗に 3 にクランプされていたエンジンバグ修正。

**DMS (PFC) の診断 — 次ラウンドの柱状再設計**:
- ランダムグラフ反回帰では選択的アトラクタが保持できない: 募集が全ネットに
  広がり (テンプレート 2812 スパイク/300ms ≒ 半分の細胞)、全地球的 E-I が
  probe の感覚応答を抑制 (sensory 寄与 ≈ 0)。population-vector デコーダ
  (遅延テンプレ vs probe 応答の cos) は match/lure とも ≈1.0 で判別不能。
- コインシデンス-2 KC ゲート、STDP 窓ヘッブ結合、ffge 適格性は実装済み。
- **次手順: 細胞を 2D シートに置き、距離依存接続 (Hellwig 2000/Holmgren 2003)
  + 入力トポグラフィ (Goldman-Rakic の柱) で局所アトラクタに閉じ込める。**

**種ロバスト性 (OPEN)**: seed42 は episode が立たない (CA3 活動の種差が
encode フロア 0.050 と噛み合わない)。修正案: 工期ホームオスタシスによる
mossy 駆動の正規化 (構築時に標準応答へ較正)。適応閾値 (3×EMA) は試したが
未解決 (タングリング再発) — a997872 の固定フロア 0.050 を現行最良として保持。

## 13. 第三ラウンド: infant1 言語スイート 4/4 + エンジン配線バグ2件修正

### 13.1 エンジン配線バグ (全回路に影響 — 発見と修正)

**バグ1 (sampler clamp)**: `make_random_fanin_dist` の部分 Fisher–Yates で
`idx >= avail` (残数) と比較すべき所を絶対 index と clamped → 後半の標本が
使用済み領域に巻き戻り、重複辺 + 実効ファンイン半減が**全回路**で発生。
修正: `idx >= n_pre` と比較 (index は index と比較する)。
検証: /tmp/sampdiag2 24×24 で重複 271/559 → 0、row0 が 23 種の distinct post。

**バグ2 (scratch 再利用 + 40 cap)**: 上の修正だけでは不十分だった。
(a) `scratch` が post ループの外で初期化されていた → 連続する post が同じ

### 13.3 L2 で見つかった機構と失敗

- **加算 LTP + 行正規化 = 質量略奪**: 絶対加算後に全行リスケールすると、
  最後に更新された辺が行質量を独占し、誤った対 (0→2) が学習された。
  正規化行では乗算 LTP (w←w×(1+η) 後 cap→正規化) により共有率が
  遷移確率へ収束する。η_trp=0.15 で L4 20/20 (旧: 1/20)。
- **falling edge エコー**: caregiver は咆哮の終了後に応答する (rising edge
  では重なり 0/8)。ただし VocalMotor が咆哮終了時に token を 0xff に
  リセットすると、falling edge で「何を言ったか」が消える →
  最後の音節を保持するよう修正 (speaking()==false が無声を示す)。
- **弓状学習窓**: audio→motor STDP 窓 τ=0.25s では咆哮間隔 (~0.73s) より
  長く、前の咆哮の運動痕に別音節のエコーが誤結合した。τ=0.08s
  (間隔 ≪ 咆哮間隔) で直前咆哮のみ学習 → 6/8。
